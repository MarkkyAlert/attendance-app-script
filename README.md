# ระบบเช็คชื่อนักเรียน

ระบบเช็คชื่อสำหรับ **ครูประจำชั้น 1 คน / 1 ห้อง** เขียนด้วย Google Apps Script แบบ container-bound
ใช้ Google Sheets เป็นฐานข้อมูล เปิดใช้ผ่าน Web App 3 หน้า — หน้าครู / หน้าผู้ปกครอง / หน้าพิมพ์

ผลลัพธ์ปลายทางคือเอกสาร **ปพ.6** ที่ครูต้องส่งโรงเรียนจริง ตัวเลขในระบบจึงไม่ใช่แค่ตัวเลขบนจอ

---

## โมเดลการขายที่กำหนดรูปร่างของทุกอย่าง

ขายแบบ **ครูแต่ละคน copy Spreadsheet + Script ไปเป็นของตัวเอง** ไม่ใช่ระบบกลางของโรงเรียน
ข้อนี้ไม่ใช่รายละเอียดทางธุรกิจ แต่เป็นข้อจำกัดทางวิศวกรรมที่อธิบายเกือบทุกการตัดสินใจในโค้ด:

| ผลที่ตามมา | ความหมายเวลาเขียนโค้ด |
|---|---|
| **push โค้ดให้ลูกค้าเก่าไม่ได้** | `restoreBackup` คือช่องทางเดียวที่ครูซึ่งซื้อไปแล้วจะได้เวอร์ชันใหม่ ห้ามทำพัง |
| **รัน migration กับข้อมูลลูกค้าไม่ได้** | migration ต้องซ่อมตัวเองตอน runtime และต้อง idempotent |
| **ดู log / debug ของลูกค้าไม่ได้** | error ต้องอธิบายตัวเองให้ครูอ่านรู้เรื่อง ไม่ใช่ stack trace |
| **แต่ละสำเนาแยกจากกันสิ้นเชิง** | ไม่มี "ผู้ใช้" หลายคน ไม่มี tenant ไม่ต้องมี ACL ระหว่างครู |
| **Script Properties / OAuth / trigger ไม่ติดไปกับการ copy** | ครูต้องกดเมนูติดตั้งและอนุญาตสิทธิ์เองทุกครั้ง |

---

## ติดตั้ง (สิ่งที่ครูต้องทำ)

1. Copy Spreadsheet (สคริปต์ติดไปด้วยเพราะเป็น container-bound)
2. เปิดชีต → เมนู **🎓 ระบบเช็คชื่อ → ⚙️ ติดตั้งระบบ (ครั้งแรก)** → อนุญาตสิทธิ์
3. Apps Script → **Deploy → New deployment → Web app**
   - Execute as: **Me**
   - Who has access: **Anyone** (ต้องเป็นแบบนี้ เพราะหน้าผู้ปกครองอยู่ใน deployment เดียวกัน)
4. เปิด URL แล้ว **ตั้งรหัสครูทันที**

> ⚠️ **ข้อ 4 ต้องทำก่อนส่ง URL ให้ใคร**
> `runInitialSetup` เรียกได้โดยไม่ต้องล็อกอิน และเงื่อนไขเดียวคือ "ยังไม่มีรหัสครู"
> ใครก็ตามที่เปิด URL ก่อนแล้วตั้งรหัสสำเร็จ จะได้เป็นเจ้าของระบบนั้นทันที
> ช่องเวลาเสี่ยงคือตั้งแต่ deploy เสร็จจนครูตั้งรหัสเสร็จ

**deployment ไม่ได้อยู่ในโค้ดและไม่ติดไปกับการ copy** — ต้องกด deploy จาก Apps Script UI เองเสมอ

## พัฒนาต่อ

ทดสอบในเครื่องไม่ได้ วงรอบจริงคือ:

```bash
clasp pull && clasp push
```

แล้วไปสร้าง deployment version ใหม่จาก Apps Script UI และทดสอบบนของจริง
`clasp push` / `pull` **เขียนทับทั้งไฟล์ ไม่ merge แบบ git** จึงต้อง `clasp pull` ก่อนเริ่มงานทุกครั้ง
และห้ามแก้บนเว็บพร้อมกับแก้ในเครื่อง
